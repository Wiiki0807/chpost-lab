# Lab 2：Agent 模式（12 分鐘動手）

## 目標

用一句需求，讓 agent 端到端完成一個新端點：改多個檔案、自己跑測試、失敗自己修。
然後**你要逐行 review 它做了什麼**。

---

## 開始前

切換到 **Agent mode**（Chat 面板上方的模式選單）。

Agent mode 跟 Ask / Edit 的差別：**它會自己決定要看哪些檔案、改哪些檔案、跑什麼指令。**
你不用告訴它去看 `volume.py`，它會自己找。

建議先 commit 目前的工作，這樣待會 review diff 比較乾淨：

```powershell
git add -A
git commit -m "lab1 done"
```

---

## 任務：實作 SLA 端點

把這段貼進 Agent mode：

```text
實作 GET /api/v1/sla 端點，回傳各投遞局的時效達成率，T+2 天內送達視為達標。
支援 region 與 month 兩個 query 參數。
請照專案既有 /api/v1/volume 的三層寫法（router / service / repository）。
補上 pytest，並確保 pytest 全部通過。
不要修改資料庫 schema。
```

### 這個 prompt 為什麼有效

拆開來看，它包含了四件事。**這就是好需求的公式。**

| 元素 | 對應的句子 |
|---|---|
| 明確範圍 | `GET /api/v1/sla`、`region` 與 `month` 兩個參數 |
| 驗收條件 | `補上 pytest，並確保 pytest 全部通過` |
| 參考範例 | `照專案既有 /api/v1/volume 的三層寫法` |
| 禁止事項 | `不要修改資料庫 schema` |

少掉任何一項，結果都會明顯變差。

---

## 跑的時候看這四件事

不要滑手機，盯著它做：

1. **它在讀哪些檔案** — 它在自己找 context
2. **它同時改了幾個檔案** — 這是 Edit 模式做不到的
3. **它自己跑了 `pytest`** — 這是關鍵，它有回饋迴路
4. **測試失敗後它自己修** — 這就是 agent 跟 chat 的本質差異

---

## 跑完後一定要做的事

### 1. 逐檔 review diff

```powershell
git diff
```

**至少找出一處你不同意的決定。** 待會講評會問你。

常見可以挑剔的地方：

- 錯誤處理的方式跟既有程式碼不一致
- 測試只測了正常路徑
- 變數命名不符合專案慣例
- 多加了不必要的抽象層

### 2. 試試 checkpoint 回溯

在 Chat 的歷史紀錄裡找到某一步，把它 undo 掉，看檔案狀態怎麼變。
**這是你的後悔藥，一定要知道它在哪。**

### 3. 試試中途 steering

重新跑一次，跑到一半按停止，補一句：

```text
先不要動 repository 層，只改 service。
```

看它怎麼調整方向。

## 選做：反面教材

開一個新的 agent session，故意下模糊 prompt：

```text
幫我優化這個專案的效能
```

**看它改到第三個檔案的時候按停止。**

這不是 Copilot 笨，是你沒有給驗收條件。回頭對照上面那個成功的 prompt，
你就會懂為什麼要寫那四個元素。

---

## 非撰碼路線（PM / QA / 架構師）

不寫 code，改做**需求品質的實驗**。

用同一個功能寫出三個版本的 prompt：

1. 一句話版：`加一個 SLA 端點`
2. 加上驗收條件版
3. 完整四元素版（範圍 + 驗收 + 參考 + 禁止）

分別丟給 agent 跑（每次開新 session），記錄：

- 它改了幾個檔案
- 花了多久
- 產出的品質差異

**這個實驗的結論可以直接用在你寫 user story 上。**

---

## 觀看版重點

記住白板上那三行字：

> **Agent 三原則**
>
> 1. **小任務**：能一句話說清楚驗收條件
> 2. **可驗證**：有測試或指令能證明它做對了
> 3. **必 review**：diff 要一行一行看

還有一個判斷訊號：**當 agent 開始在同一個地方來回改第三次，就該停手自己寫。**

## 卡住怎麼辦

| 問題 | 處置 |
|---|---|
| agent 跑很久沒動靜 | 按停止，把任務拆小再試 |
| 它改壞了一堆檔案 | `git checkout .` 全部還原，重新下更明確的 prompt |
| 測試一直修不好 | 正常。這就是要你看到的「agent 的極限」 |
| 完全跟不上 | 執行 `git checkout lab-3-start`，下個模組直接跟上 |
